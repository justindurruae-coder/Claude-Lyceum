# Cómo escribir un buen prompt

1. **Contexto:** quién eres, para quién es, qué vendes.
2. **Tarea:** un verbo claro (escribe, compara, resume, critica).
3. **Formato:** tabla, lista, longitud máxima.
4. **Límites:** qué no debe hacer ("no inventes datos", "sin promesas de resultados").
5. **Ejemplo:** pega una salida que te gustaría imitar.
6. **Itera:** pide una mejora concreta, no "hazlo mejor".

Regla práctica: si un compañero nuevo no podría hacer la tarea con tu mensaje, Claude tampoco.
