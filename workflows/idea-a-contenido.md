# De idea a contenido publicado

Proceso de 5 pasos que encadena los prompts del repo.

| Paso | Qué haces | Recurso |
|---|---|---|
| 1. Ideas | Generas 15 ideas y eliges 3 | [ideas-de-contenido](../prompts/marketing/ideas-de-contenido.md) |
| 2. Guion | Conviertes la elegida en guion | [guion-reel](../prompts/marketing/guion-reel.md) |
| 3. Revisión | Pides a Claude que critique el gancho y marque afirmaciones sin respaldo | Prompt abajo |
| 4. Producción | Grabas y editas tú | Tu herramienta |
| 5. Aprendizaje | Anotas qué funcionó con datos reales | [registro-de-decisiones](../templates/registro-de-decisiones.md) |

## Prompt del paso 3

```
Revisa este guion: [GUION].
Dime: ¿el gancho funciona en 3 segundos? ¿Qué frase sobra? ¿Qué afirmación no podría defender con un dato?
Devuélvelo corregido sin cambiar mi voz.
```

## Regla
Un humano publica. Claude propone, tú decides y apruebas antes de publicar.
