# Preparar una llamada de ventas

Para qué sirve: llegar a una llamada de descubrimiento con contexto y preguntas.

## Prompt

```
Voy a tener una llamada de descubrimiento con [NOMBRE / EMPRESA].
Lo que sé de ellos: [NOTAS, WEB, SECTOR, TAMAÑO].
Lo que vendo: [OFERTA Y PRECIO ORIENTATIVO].

Prepárame:
1. Resumen de su situación probable (marca qué es hecho y qué es suposición).
2. 8 preguntas de descubrimiento, de menos a más incómodas.
3. 3 objeciones probables y cómo responderlas con honestidad.
4. Criterio claro para decidir si es buen cliente o conviene decir que no.
5. Siguiente paso concreto que propondré al cerrar.
```

## Notas
Pega solo información que sea tuya o pública. No incluyas datos personales sensibles de terceros.
