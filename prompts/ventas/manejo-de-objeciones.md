# Manejo de objeciones

Para qué sirve: preparar respuestas honestas a las objeciones más comunes.

## Prompt

```
Mi oferta: [OFERTA]. Precio: [PRECIO]. Cliente típico: [PERFIL].
Objeción que escucho: "[OBJECIÓN]".

Dame:
1. Qué suele significar de verdad esta objeción (3 posibilidades).
2. Una pregunta para averiguar cuál es.
3. Una respuesta para cada posibilidad, en tono calmado, sin presión.
4. Cuándo aceptar el "no" y cerrar bien la conversación.
```

## Ejemplos de objeción
"Es caro", "Lo tengo que pensar", "Ahora no es buen momento", "Ya lo hago yo".
