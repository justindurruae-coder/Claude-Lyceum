# Resumen de investigación

Para qué sirve: convertir un texto largo o varias fuentes en una decisión.

## Prompt

```
Te paso [ARTÍCULO / TRANSCRIPCIÓN / NOTAS]. Mi objetivo: decidir [DECISIÓN].

Entrégame:
1. Las 5 ideas clave en una línea cada una.
2. Qué es dato comprobable y qué es opinión del autor.
3. Qué falta para decidir con seguridad.
4. Recomendación con razonamiento y riesgos.
5. Una frase de conclusión.

Si algo no está en el texto, dilo; no lo completes de memoria.
```
