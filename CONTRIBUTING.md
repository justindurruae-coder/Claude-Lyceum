# Contributing / Cómo contribuir

Thanks for helping. / Gracias por ayudar.

## What we accept

- New prompts, workflows, agents and templates
- Fixes to existing resources
- English translations of Spanish resources (and the reverse)

## Resource format

Every prompt or template is one `.md` file with this header:

```markdown
---
titulo: Short name
area: marketing | ventas | productividad | agentes | otro
probado-con: Claude model or tool used
actualizado: YYYY-MM-DD
---
```

Then: what it is for, the prompt or template itself, with `[BRACKETS]` for the user's data, and one example of the output.

## Rules

1. One resource per file. Name says what it contains.
2. No personal data, client names, API keys or credentials. Ever.
3. Only submit work you wrote or have the right to share under MIT.
4. Test the prompt before opening the PR and say what you tested it with.
5. No claims of guaranteed results (income, followers, sales).

## Process

1. Fork the repo and create a branch.
2. Add or edit the file and update the list in `README.md` and `README.es.md`.
3. Open a pull request using the template.

By contributing you agree your work is released under the [MIT License](LICENSE).
