# Claude Lyceum

Kit open source de flujos de trabajo, prompts, agentes y plantillas prácticas de Claude para emprendedores y creadores. Gratis para descargar, copiar y adaptar.

[Read in English](README.md) · [Licencia MIT](LICENSE) · [Cómo contribuir](CONTRIBUTING.md)

## Qué es

Una biblioteca de recursos listos para usar, sin teoría. Cada archivo es copiar y pegar: lo abres, rellenas los `[CORCHETES]` y lo ejecutas en Claude.

## Qué hay dentro

| Carpeta | Contenido |
|---|---|
| [`prompts/`](prompts) | Prompts reutilizables por área: marketing, ventas, productividad |
| [`workflows/`](workflows) | Procesos paso a paso que encadenan varios prompts |
| [`agents/`](agents) | Plantilla de `CLAUDE.md` y subagentes para Claude Code |
| [`templates/`](templates) | Documentos para rellenar (brief, calendario, registro de decisiones) |
| [`docs/`](docs) | Guías y notas del proyecto |

## Empezar

1. Entra en una carpeta y abre un archivo.
2. Copia el prompt o la plantilla en Claude.
3. Sustituye todo lo que esté entre `[CORCHETES]` por tu contexto.
4. Itera. Los prompts son punto de partida; el resultado mejora con tus datos reales.

Para descargar todo:

```bash
git clone https://github.com/justindurruae-coder/Claude-Lyceum.git
```

O usa **Code → Download ZIP** en GitHub.
