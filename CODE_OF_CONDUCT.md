# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful. No harassment, discrimination or personal attacks.
- Give feedback on the work, not the person.
- Assume good faith; ask before assuming.
- No spam, self-promotion unrelated to the project, or misleading claims.

Maintainers may edit or remove contributions and block users who break these rules.
Report problems by opening a private security advisory on this repository or by contacting the maintainer through their GitHub profile.
