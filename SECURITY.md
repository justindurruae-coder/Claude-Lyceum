# Security Policy

This repository contains documents and prompts, not executable software. The main risks are leaked secrets and unsafe agent instructions.

## Reporting

If you find a credential, personal data or an unsafe instruction in this repo, use **Security → Report a vulnerability** on GitHub. Please do not open a public issue for leaked secrets.

## Rules for contributors

- Never commit API keys, tokens, passwords or personal data.
- Agent and automation examples must not include destructive actions (delete, overwrite, publish) without a human confirmation step.
